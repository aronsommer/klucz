Rzeczowniki – Nomen

Das Wortende zeigt fast immer das Geschlecht · Stamm + Endung

1. Rodzaje – Geschlechter · on (er), ona (sie), ono (es)

Es gibt keine Artikel: dom = das Haus, ein Haus.

Geschlecht Ende Beispiele
männlich · on (er) Konsonant brat (Bruder) · dom (Haus) · kot (Katze)
weiblich · ona (sie) -a kawa (Kaffee) · mama (Mama) · szkoła (Schule)
Neutrum · ono (es) -e, -ę, -o morze (Meer) · imię (Vorname) · dziecko (Kind)

2. Wyjątki – Ausnahmen · auswendig lernen

männlich auf -a mężczyzna (Mann) · kolega (Kollege) · tata (Papa)
weiblich auf Konsonant noc (Nacht) · rzecz (Sache) · twarz (Gesicht)
-ość: fast alle weiblich miłość (Liebe) · wiadomość (Nachricht) · aber gość (Gast): m.
weich: -ń, -ć, -ś, -l … Geschlecht unklar: dzień (Tag): m. · jesień (Herbst): w.

3. Liczba mnoga – Mehrzahl · außer männlichen Personen

ten, ta, to (dieser, diese, dieses) → Mehrzahl: te (diese)

Wortende Mehrzahl Beispiele
die meisten -y kot → koty (Katzen) · mama → mamy (Mamas)
nach k, g -i ptak → ptaki (Vögel) · noga → nogi (Beine)
meist nach c, cz, sz, rz, ż, j, l und weichen Lauten -e ulica → ulice (Straßen) · noc → noce (Nächte)
Neutrum auf -o, -e -a okno → okna (Fenster) · pole → pola (Felder)

4. Liczba mnoga: mężczyźni – Mehrzahl: Männer

-t, -sta → -ci, -ści student → studenci (Studenten) · turysta → turyści (Touristen)
-k, -iec → -cy Polak → Polacy (Polen) · Niemiec → Niemcy (Deutsche)
-rz, -cz → -e lekarz → lekarze (Ärzte) · gracz → gracze (Spieler)
einige Wörter → -owie pan → panowie (Herren) · syn → synowie (Söhne)

Unregelmäßige Mehrzahl

człowiek → ludzie · rok → lata Menschen · Jahre ganz anderes Wort
dziecko → dzieci Kinder nicht dziecka (Neutrum → -a)
ręka → ręce Hände nicht ręki (nach k → -i)
dzień → dni Tage nicht dzienie (weich → -e)
brat → bracia Brüder nicht braci (t → ci)
część → części · rzecz → rzeczy Teile · Sachen nicht częście, rzecze (→ -e)
